          Worktrees
          
    
          
      A second checkout of this repository, on its own branch, that a session works in — so a turn
      cannot touch the tree you have open. The branch is there afterwards to merge, look at, or
      throw away.
    
          
    
          
    
          
    
      
      
          
      
      
              
  
          
          


  
          
    
          Hooks
          
    
          
      Commands that run around a tool call. One that exits non-zero stops the call and its reason goes
      back to the model — a hook can take things away and can never allow them, so a project can stop
      you doing something without being able to do it for you.
    
          
    
          
      Yours in ~/.openmirror/hooks.json run as written. A project's are code you did not
      write, so the first time one would fire you are asked, and the answer lasts for the session.
    
          
    
          
    
      
          
      
              
    
          
  
          
          


  
          
    
          Review this turn's changes
          
    
          
      Each block is one change. Put back the ones you disagree with and leave the rest — the undo of
      "the agent changed this and got it right" is not the undo of the turn.
      Nothing is written until you press the button.

          New session
          
    
    
    
    
    
          
      A long tool list costs a small model accuracy: a 12B model given every tool failed a
      five-step browser task that it finished in twenty-six seconds with only the browser
      ones. Leave this alone on a large model.
    
          
    
    
      
      
    
  
          
          


  
          Rewind
          
  
          
    Put files back to how they were before a turn. This undoes that turn and every
    one after it — undoing one in the middle would leave a state that never existed.
  
          
  
          
    Only the agent's own file edits are recorded. Anything a shell command wrote is
    not covered, and cannot be: snapshotting the whole filesystem before every
    command is not something anyone wants.
  
          
  
            
  
    
            
    
              
            


  
            Memory
            
  
            
    What openmirror remembers about you between conversations. It is off until you turn
    it on, everything stored is listed here, and you can remove any of it or all of it.
  
            

  
  

  
            
  
              

  
    
    
              
    
                
              


  
              Settings
              

  
  
              Theme
              
  
              
    
              
    Automatic
    
  
              

  
              
    
    
    
  
              

  
              
    
              
      openmirror checks GitHub for a newer release and tells you. It never downloads or
      installs anything on its own: downloading waits for you to press the button, and
      installing waits for you to confirm, because a message that appears over work you are
      doing is a message that gets dismissed without being read.
    
              
    
              
    
              
    
              
    
      
      
              
      
      
                  
    
              
      
      
    
              
    
              
      A downloaded installer is checked against the SHA256 published in the same release before
      it is offered to run. That is an integrity check, not a signature: it catches a truncated
      download and a mirror serving last week's build, and it does not prove who published
      anything.
    
              
  
              

  
              
    
              
      Which browser openmirror drives — both when the agent browses and when it searches.
      Chromium comes with the browser extra and is always the right version for it;
      your own Chrome has the codecs Chromium lacks and looks like an ordinary visitor
      to sites that check. Firefox and WebKit are different engines, not reskinned
      Chromium.
    
              
    
              
      Your profile and logins are per browser. Switching means signing in again in the
      new one — once, by hand, which is the arrangement that keeps openmirror from ever
      needing a password.
    
              

    
                

    

    
                

    
      
      
                
      
                    
  
                

  
                
    
                
      What answers each kind of request. Chat and embedding are chosen separately on
      purpose: the model you think with and the model you remember with are different
      decisions, and they send different things to different places.
